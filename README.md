# 페이저 계산기 (회로이론용)

복소수 ↔ 페이저 변환과 페이저 사칙연산만 하는 단순한 웹 계산기입니다.

## 기능
- **복소수 → 페이저**: `5+i` → `5.099 ∠ 11.3099°`
- **페이저 → 복소수**: `5∠30` → `4.3301 + j2.5`
- **페이저 연산** (+ − × ÷): 입력은 페이저·복소수 둘 다 가능, 결과는 두 형식으로 표시
- **일반 계산**: 사칙연산, 거듭제곱, 괄호, sin·cos·tan(및 역함수), √, π — 예: `12*1.897/2*cos(60-41.57)`
- 각도 단위: 도(°), 허수 단위 `i`/`j` 둘 다 인식, `∠` 대신 `<` 입력 가능
- 한 번 접속하면 오프라인(비행기 모드)에서도 작동 (Service Worker)

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 (예: `phasor-calc`, Public)
2. 이 폴더의 파일을 모두 업로드 (`index.html`, `app.js`, `sw.js`, `manifest.json`, `icon-192.png`, `icon-512.png`)
3. 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** 저장
4. 1~2분 후 `https://<깃허브아이디>.github.io/phasor-calc/` 접속
5. 휴대폰에서 열고 **홈 화면에 추가** → 앱처럼 사용

> 파일을 수정한 뒤에는 `sw.js`의 `CACHE` 버전(`v1` → `v2`)을 올려야 휴대폰에 새 버전이 반영됩니다.
